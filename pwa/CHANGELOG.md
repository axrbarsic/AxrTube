# Изменения PWA

## Версия 38

- Зафиксирован отрицательный результат v37 и проверки без Bluetooth.
- В Check добавлен эксперимент 3: video element с прежним контрольным MP3.
- Привязка MediaSession, источник и идентичность сохранены для сравнения.
- Переключение блокируется после старта, выбор элемента отражается в JSON.
- Это диагностический кандидат, не подтверждённое исправление на iPhone.

## Версия 37

- Зафиксирован отрицательный результат отдельной идентичности на iPhone.
- В Check добавлена явная кнопка регистрации системной медиасессии для теста 2.
- До нажатия metadata/команды не меняются; состояние включения отражается в JSON.
- ID тестового ярлыка и основное приложение сохранены, ожидается проверка Alex.

## Версия 36

- Добавлен отдельный устанавливаемый контрольный ярлык AxrTube Check.
- Изолированы ID, start URL и scope без миграции основной установки.
- Контрольный JSON различает отдельную и существующую идентичности.
- Записана очередь ограниченных экспериментов; ожидается проверка на iPhone.
- Основные playback, background, Google-вход и рекламные фильтры не менялись.

## Версия 35

- Встроен системный контрольный аудиотест внутри той же установленной PWA.
- Изолированы YouTube, HLS и пользовательское управление MediaSession/AudioSession.
- Локальный журнал жизненного цикла переживает повторный запуск, есть скачивание JSON.
- Ручная отметка результата, ограничение истории и фильтрация приватных значений.
- Причина неправильного открытия ярлыка пока не считается устранённой.

## Версия 34

- В iOS Home Screen PWA возвращён автоматический Audio Session режим вместо override из v15.
- Сохранены фоновые обработчики, Play/Pause, manifest ID, аккаунт и локальные данные.
- Добавлена диагностика `audio-session-browser-owned`, Android не менялся.
- Кандидат на исправление ошибочного возврата в чужую PWA, физическая проверка ещё не выполнена.

## Версия 33

- Android: одна дополнительная отложенная попытка при второй паузе сразу после принятого resume.
- Воспроизведён отчёт v32 с промежутком 31 мс, без смены источника и позиции.
- Явная пауза/выход/ошибка отменяют ожидание; максимум два Play за короткий переход, без polling.
- Политика iPhone не расширена. Физическая Android-приёмка ожидается.

## Версия 32

- Одна повторная попытка для NO_HLS вместе с 403/LOGIN_REQUIRED, но не для NO_HLS отдельно.
- Сбой отчёта v31 локализован до плеера, на серверном получении потока YouTube.
- Тот же ролик доступен диагностическому коду с Mac, но отклоняется с публичного хоста.
- Серверный отказ не объявляется исправленным. Плеер и Google-вход не менялись.

## Версия 31

- Android/Chromium предпочитает MSE при поддержке, Play ждёт loadedmetadata.
- Убрана дополнительная Pause из обработки ошибки старта.
- Одна ограниченная попытка после AbortError без смены источника и подавления явной паузы.
- В диагностику добавлены transport и этапы подготовки. Нативный Apple HLS сохранён.
- Авторизация и блокировка рекламы не менялись; реальный Android требует повторной проверки.

## Версия 30

- Единый Google-вход для профиля и рекомендаций вместо двух последовательных согласий.
- Offline access и автоматическое обновление access token по зашифрованному refresh token.
- Сетевая ошибка не удаляет вход, параллельные обновления объединяются внутри Worker.
- Сохранены CSRF/PKCE, точный origin, изоляция credentials и binding при выходе/смене аккаунта.
- Бессрочный вход не обещается: Google Testing обычно ограничивает refresh token 7 днями.

## Версия 29

- Chromium/MSE ждёт готовности HLS manifest перед Play, отдельно проверены audio и video.
- Ожидание отменяется при закрытии, ошибки и таймаут не оставляют плеер заблокированным.
- HLS.js доставляется с собственного домена, версия закреплена, есть резервный CDN.
- Нативный HLS Safari не изменён. Физическая Android-приёмка ещё не выполнена.
- Срок Google-входа пока не продлён, refresh token не хранится.

## Версия 28

- Исправлены пустые страницы каналов из подписок: WEB lockup отделён от TV tile.
- Проверен реальный канал со скриншота: 30 распознанных роликов вместо 0.
- Сохранены порядок, continuation и исключение рекламных карточек и плейлистов.
- Плеер и авторизация не менялись.

## Версия 27

- Подтверждён реальный доступ к персональному TV browse с собственным Web OAuth.
- Главная показывает рекомендации YouTube в порядке провайдера вместо групп подписок.
- Свайп обновляет первую страницу, продолжение использует continuation и visitor.
- При ошибке обновления карточки сохраняются, Shorts фильтруются без пересортировки.
- Старая readonly-сессия предлагает отдельное подключение рекомендаций.
- Точная идентичность официальной iOS-ленте не заявляется, медиадвижок не изменён.

## Версия 26

- Отдельное согласие на расширенный YouTube scope для проверки рекомендаций.
- Обычный вход остаётся только на чтение, отказ сохраняет текущую сессию.
- Фактические права определяются ответом Google, refresh token не хранится.
- Персональная главная пока не объявляется рабочей, плеер не изменён.

## Версия 25

- Подтверждён HTTP 403 от TV browse с текущим Web OAuth, без изменения прав.
- Безопасная диагностика причины: только известные Google enums.
- Главная и рабочий вход не подменяются непроверенной персональной лентой.

## Версия 24

- Защищённый серверный маршрут проверки персональной главной по пути нативного iOS.
- TVHTML5 tiles и continuation без локального ранжирования и выдачи токенов клиенту.
- Главная ещё не переключена: требуется подтверждение совместимости Web OAuth.

## Версия 23

- Полная «Стенограмма» из плеера и меню карточки, без остановки медиасессии.
- Оглавление, разделы и абзацы по политике iOS, удаление повторов ASR.
- «Копировать всё», «Скопировано», Markdown и ручной fallback копирования.
- Публичные субтитры YouTube, no-store, точная проверка timedtext URL и video ID.
- Ограничение: Apple Translation не перенесён, показывается язык исходной дорожки.
- Локальная проверка реального ролика успешна; физическая iPhone-приёмка впереди.

## Версия 22

- Свайп вниз на главной обновляет подборку внутри приложения, без перезагрузки плеера.
- Обновление переключает группы подписок; конец списка начинает новый цикл.
- При неизменившихся роликах честное уведомление, при ошибке прежние карточки сохранены.
- Выбор языка в настройках и автоопределение из navigator.languages.
- Русский, English, Español, українська, Kreyòl ayisyen, ямайский Patwa.
- Ручной выбор сохраняется, названия роликов и каналов не переводятся.

## Версия 21

- Переключатель «Скрывать Shorts», скрытие вкладки и распознанных Shorts без удаления данных.
- Главная без Shorts использует вкладку «Видео» подписанных каналов, не фильтр длительности.
- Звёзды закрепления в существующих «Подписках», автоматическая загрузка страниц списка.
- Только установленное PWA: блокировка масштабирования страницы и overscroll-эффекта.
- Обычная вкладка, ввод, прокрутка и плеер сохранены. iPhone-жесты ожидают приёмки.

## Версия 20

- Главная ждёт проверки Google-сессии и после входа показывает аккаунт и видео подписок.
- Лента: 6 каналов по алфавиту, по 5 видео, объединение по дате без дублей.
- Кнопки личных подписок/плейлистов и загрузки следующей группы каналов.
- Статус аккаунта в настройках; повторная проверка при возврате в приложение.
- Ошибки/истечение входа не подменяются гостевой главной. Плеер и реклама не менялись.
- Персональные рекомендации YouTube не заявляются, iPhone-приёмка впереди.

## Версия 19

- Исправлен конфликт `no-referrer` и строгой Origin-проверки HTML-формы входа.
- HTML передаёт referrer только внутри сайта; OAuth callback остаётся no-referrer.
- Origin-проверка не ослаблена, добавлены проверки null/missing/cross-site запросов.
- Плеер, фон и локальные данные не менялись. iPhone-вход ожидает приёмки.

## Версия 18

- Собственный Google Web OAuth client, YouTube Data API включён с согласия владельца.
- «Войти через Google» во вкладке «Вы», server authorization-code/PKCE/state.
- Зашифрованная HttpOnly cookie с read-only access token максимум на час.
- Отдельные подписки и плейлисты Google, без подмены локальной медиатеки.
- Защита logout epoch, same-origin POST и отсутствие токенов в JS/отчётах.
- Testing mode; физическая приёмка входа и публичная Google verification впереди.
- Фоновый плеер, AAC-LC и обновление оболочки не менялись.

## Версия 17

- Принято Alex: автоматическое продолжение после сворачивания, с короткой паузой.
- Startup/resume проверка актуальной версии; pinned release для скриптов и CSS.
- Нет перезагрузки посреди медиасессии; новая версия применяется после закрытия.
- Защита от циклического reload и отката на ответ старого узла хостинга.
- Network-first оболочка с offline fallback и очисткой только старых shell caches.
- Google-вход исследован и подготовлен в отдельном проекте, не объявляется готовым.

## Версия 16

- По отчёту v15 исправлен порядок pause -> hidden (139/171 ms), при котором
  восстановление раньше вообще не запускалось.
- Кандидат ранней паузы действует 400 ms и требует следующего hidden.
- Явные команды паузы и наблюдаемый ввод в native controls отменяют кандидата.
- Один play, прежние source/time; без переключения на другой плеер или таймеров.
- Физическая приёмка на iPhone пока не выполнена.

## Версия 15

- Обработан переход в фон общего плеера без смены media element/источника.
- Явный Audio Session playback по поддержке браузера, Media Session state.
- Одна попытка восстановления паузы в первые 2 секунды hidden-перехода.
- Явная пауза и системное interrupted-состояние имеют приоритет.
- В отчёте появились audioSessionState/type и background-resume события.
- Проверено адресными тестами; iPhone-приёмка пока не выполнена.

## Версия 14

- Отчёт iPhone v13: xFrGuyw1V8s не получил источник, оба клиента вернули
  LOGIN_REQUIRED. Следующая проверка того же ролика на публичном сайте получила
  HLS, то есть отказ непостоянный. Это не ошибка скорости или фонового плеера.
- Один автоматический повтор через 600 ms только для набора отказов
  PLAYER_LOGIN_REQUIRED/PLAYER_HTTP_403. Другие ограничения не повторяются.
- Коды остаются в отчёте, пользователю показывается понятное сообщение.
- После отказа плеер переводится в паузу, ID ролика включается в отчёт.
- Постоянные ограничения YouTube этим не устранены. Рекламного fallback нет.

## Версия 13

- Подтверждение Alex: видео и аудио играют с нормальной скоростью после v12.
- Мобильная оболочка на основном адресе; прежний стенд доступен в `/lab`.
- WEB-каталог YouTube: поиск, подсказки, pagination, гостевая главная, каналы,
  похожие, Shorts. Порядок выдачи сохранён, рекламные renderers исключены.
- Один общий плеер для полноэкранной страницы просмотра и мини-плеера.
- Локальная история с позицией, watch later, liked, очередь и подписки.
- SponsorBlock sponsor/selfpromo с ограниченным серверным кэшем.
- Переключение video/audio, скорость, PiP по API, share по поддержке браузера.
- Поздний ответ resolver после закрытия не возобновляет плеер.
- Нет зависимости от компьютера, аккаунт и реальные YouTube downloads впереди.
