# Передача из облачной сессии (13–14 ноября 2026)

## Что сделано

### PWA перенесён на Cloudflare Workers
- Адрес: https://axrtube.axrbarsic.workers.dev (Worker `axrtube`, аккаунт Cloudflare владельца).
- Исходники: папка `pwa/` на ветке `claude/new-session-wtskbg`. Основа: экспорт PWA v38.
- Сборка и проверка: `cd pwa && npm run build && npm run validate`, тесты `node scripts/test*.mjs` (все зелёные).
- Перезаливка: `pwa/scripts/deploy-cloudflare.sh`, инструкция в `pwa/DEPLOY.md`.
  Ключ Cloudflare в репозитории НЕТ: владелец создаёт новый токен
  (шаблон «Edit Cloudflare Workers») и задаёт его только в окружении.
- Google-вход работает на новом адресе. Client ID публичный, Client secret и
  ключ шифрования cookies лежат только в секретах Cloudflare.

### Главный результат: баг с чужим ярлыком на Lock Screen
На новом origin нажатие карточки Now Playing на заблокированном iPhone
возвращает в правильное приложение (проверено владельцем: страница
AxrTube Check и основное приложение). Значит, причина была в окружении
старого origin (старая установка, его Service Worker или данные), а не в
плеере или коде YouTube. Что именно из этого, не выяснено.

### Нерешённое: YouTube блокирует серверы Cloudflare
- Журнал Workers показывает `PLAYER_LOGIN_REQUIRED` и `PLAYER_HTTP_403`
  («подтвердите, что вы не бот») для IOS, VISIONOS и ANDROID_VR.
- Блокировка волнами: тот же дата-центр (MIA) то пропускает, то нет.
  Удачные запуски были (Android 12.11 22:52 UTC, iPhone 13.11 17:44 UTC).
- Добавлены запасные пути: клиент ANDROID_VR и мост к старому сайту
  (`LEGACY_STREAM_BRIDGE`). Старый сайт тоже получал отказ (502).
- Включена диагностика `STREAM_PROBE=true`: при запуске ролика проверяет
  анонимные клиенты, запрос с BotGuard-токеном телефона, запрос с
  токеном вошедшего пользователя и прямой запрос из браузера телефона.
  Результаты в журнале Workers (строки `PROBE`, `RESOLVE_OK`, `RESOLVE_FAIL`).
  Владелец ещё не запускал ролики после включения. После выводов
  диагностику выключить (`STREAM_PROBE=false` при перезаливке).
- Получать поток от имени аккаунта постоянно НЕ включать без явного
  согласия владельца (риск ограничения аккаунта).

  на телефоне, блокировки датацентров нет). Задача: перенести внешний вид
  и поведение PWA в нативное приложение экран за экраном.

- Предложенный порядок экранов: главная лента → экран просмотра → канал →
  поиск → вкладка «Вы» с подписками → настройки.
- Не трогать работающие нативный плеер, фон, Lock Screen, PiP, Audio Only,
  загрузки, Share Extension, Keychain.
