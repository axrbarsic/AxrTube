# План: AxrTube как YouTube для iOS

Цель — функционально и визуально повторить официальное приложение YouTube для iPhone. Исключение — реклама: AxrTube её не показывает и не загружает.

## Что сохраняется сверх YouTube

- Блокировка рекламы: собственный AVPlayer без рекламных вставок, SponsorBlock.
- Фильтр «только русские ролики» для главной, рекомендаций и поиска.
- Стенограмма с переводом на русский и копированием в буфер обмена.
- Локальная озвучка и выжимки.
- Режим «Только аудио» — в настройках плеера.

## Что удаляется

- Девять тем и выбор иконки. Остаются системная, тёмная и светлая тема в палитре YouTube.
- Осциллограф и эквалайзер, DeArrow, RSS-ленты, закреплённые каналы.
- Жесты плеера, которых нет в YouTube: свайп влево/вправо на соседний ролик, двойной тап по центру для масштаба, двухпальцевый тап.
- Пояснительные разделы настроек, не управляющие поведением.
