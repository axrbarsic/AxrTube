# AxrTube iOS: аудит и план приведения к YouTube iOS

Дата: 15 ноября 2026. Аудит и план; статус выполнения — в конце документа.

Цель Alex: поведение, логика и внешний вид = официальный YouTube для iOS.
Два исключения, ради которых приложение существует:

1. Рекламы нет никогда (собственный AVPlayer, SponsorBlock).
2. Полная стенограмма каждого ролика (с переводом и копированием).

## Как проводился аудит и чему можно верить

- Прочитан production-код iOS: навигация, ленты, карточки, страница просмотра,
  плеер, мини-плеер, поиск, настройки, канал, Shorts, комментарии, модели, API.
- Сравнение с YouTube iOS сделано по памяти о приложении, без живого
  параллельного просмотра и без свежих снимков экрана. Пиксельные размеры
  нужно сверять на iPhone рядом с официальным приложением.
- Тесты и сборка в рамках аудита не запускались (диск 9 GiB, CRITICAL).
  Пункты с пометкой «проверить» выведены из чтения кода, а не воспроизведены.

## 3. План работ

Каждый этап: одна связная граница → адресные тесты → одна подписанная сборка →
установка поверх → вердикт Alex на iPhone → README/CHANGELOG, commit, push.

### Этап A. Подготовка (до любых правок UI)
- A1. Решения 0.1–0.4.
- A2. Освободить диск, прогнать существующие тесты (119 файлов), записать исходное состояние.
- A3. Снять эталонные экраны YouTube iOS, сложить в `docs/screenshots/reference/`.

### Этап B. Защита исключений (P0)
- B1. Shorts на собственном AVPlayer, убрать iframe-путь на iOS (1.1). Тест: ни один пользовательский путь iOS не создаёт WKWebView для воспроизведения.
- B2. Раздел SponsorBlock в настройках iPhone (1.2).
- B3. Стенограмма: сверить доступность на каждом ролике (ручные и авто-субтитры, локальное распознавание при их отсутствии), перевод, копирование всего текста. Точки входа: чип «Текст видео», описание, мини-плеер.

### Этап C. Ошибки логики (P1)
- C1. Языковой фильтр: состояние «проверяем» вместо пустого экрана, автоподгрузка до заполнения экрана, пакетная проверка без перезапуска, сохранение порядка сервиса (1.3–1.5).
- C2. Честные результаты действий: тост только после ответа сервера, ошибка показывается (1.6).
- C3. Повторный тап вкладки (1.8), продолжение ролика на паузе (1.9), двойной запрос (1.10).
- C4. Двойной тап по половинам экрана, 10 с, накопление (1.11).

### Этап D. Каркас как в YouTube
- D1. Верхняя панель: убрать настройки, добавить AirPlay; колокольчик — только если будет API уведомлений.
- D2. Нижняя панель: залитые иконки выбранной вкладки, размеры по эталону.
- D3. Главная: убрать заголовок, пояснение и служебные чипы; серверные чипы тем; порядок сервиса без примеси подписок; полки Shorts.
- D3a. Обновление главной ленты свайпом вниз — как в YouTube (требование Alex, 15.11):
  - Как в YouTube: потянул вниз → индикатор под верхней панелью → новый запрос
    главной без continuation → лента целиком заменяется свежим ответом сервиса
    в его порядке, с первой позиции, старые подгруженные страницы сбрасываются.
    Без тостов. Повторный тап по вкладке «Главная» делает то же: прокрутка
    вверх, затем обновление. После долгого отсутствия лента обновляется сама.
  - Сейчас (`YTHomeFeedView.refreshFeed`, `HomeViewModel.refresh`): лента
    заменяется снимком «рекомендации + подписки» с локальной пересортировкой;
    после обновления показывается тост «Новых видео пока нет / Рекомендации
    обновлены»; есть чип «Обновить ленту»; `refreshIfStale` (15 минут) на новом
    экране главной не вызывается; повторный тап вкладки не обновляет.
  - Подзадачи: (1) замена ленты чистым ответом сервиса без примеси и
    пересортировки; (2) убрать тосты и чип; (3) сброс continuation и позиции
    прокрутки; (4) при ошибке сети оставить прежнюю ленту и показать
    сообщение; (5) обновление по повторному тапу вкладки и по возврату в
    приложение после паузы; (6) с фильтром «только русские» — не показывать
    пустой экран, пока идёт проверка; (7) проверить на iPhone, что каждый
    свайп действительно приносит другой набор рекомендаций, а не тот же.
  - Приёмка: рядом с YouTube на одном аккаунте — тот же вид индикатора, полная
    замена ленты, возврат к началу, нет дублей и «залипших» старых карточек.
- D4. Подписки: лента каналов сверху, чипы, лента роликов. Закрепление каналов перенести в «Все».
- D5. «Вы»: шапка, полки истории и плейлистов, строки; настройки шестерёнкой.

### Этап E. Данные для карточек и страницы просмотра

### Этап F. Страница просмотра и плеер

- F2. Шторка настроек плеера: качество, скорость, субтитры, таймер сна, блокировка экрана, Audio Only.
- F3. Блок под плеером: канал с «Подписаться», лайки со счётчиком, действия, превью комментария.
- F4. Кнопка полного экрана, жесты свайпа, ландшафтные кнопки.
- F5. Описание: статистика, главы, вход в стенограмму.

## 4. Что скопировать нельзя или не нужно

- Реклама, Premium-ограничения, покупки — намеренно отсутствуют.
- Создание и загрузка видео, Ремикс, прямые эфиры с чатом и донатами, Chromecast — нет открытого пути; для каждого нужен отдельный вердикт «делаем / скрываем».
- Алгоритм рекомендаций — берётся ответ сервиса, свой не воспроизводится.
- Название и логотип остаются AxrTube.
