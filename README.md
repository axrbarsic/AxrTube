# iPocketTube

Нативный Swift/SwiftUI YouTube-аудиоклиент для iPhone: один тап по ролику запускает аудио, продолжает загрузку в локальную офлайн-коллекцию и оставляет управление на экране блокировки, в Dynamic Island и на AirPods.

> **Статус:** активная разработка. Проект собирается из исходников и не распространяет готовые IPA.

## Что умеет iPocketTube

- **Audio-first поток:** обычный тап запускает аудио без полноэкранного видеоплеера; компактный мини-плеер остаётся над навигацией.
- **Progressive audio:** совместимый поток начинает воспроизводиться до завершения загрузки, а подтверждённые диапазоны становятся тем же офлайн-ресурсом.
- **Офлайн-коллекция:** аудио и видео, прогресс, повтор/отмена, удаление, лимит хранилища, время загрузки и стабильная история воспроизведения.
- **Надёжная докачка:** crash-safe manifest и карта диапазонов, продолжение после потери сети/перезапуска, обновление истёкшего media URL и проверка HTTP Range без повторной загрузки уже подтверждённых байтов. Пользовательский запуск атомарно забирает незавершённую задачу у фонового supervisor, а поздние ответы отменённых диапазонов игнорируются.
- **Фон и блокировка:** background audio, Lock Screen, Dynamic Island, AirPods и системные команды Play/Pause/Seek.
- **Восстановление аудио:** единая source-aware state machine для пересекающихся системных interruptions и Siri/spoken prompts, смены Bluetooth-route и сброса media services; возобновление происходит один раз только после освобождения всех внешних аудиоисточников, а ручная пауза не вызывает самовольный resume.
- **Каталоги:** Поиск с отдельной обновляемой лентой рекомендаций, Главная/рекомендации, Подписки, История, плейлисты и «Каналы» — алфавитный список подписок YouTube с переходом в ленту выбранного канала. Строгий режим «Только русскоязычные ролики» включён по умолчанию для явного поиска: язык запроса может быть любым, а результаты проходят проверку доступных YouTube-метаданных аудиодорожек и автотранскрипции. Неопределённые ролики в строгом режиме исключаются; фильтр можно выключить. Очистка запроса сразу возвращает discovery-ленту, а pull-to-refresh обновляет текущий контекст без устаревшей выдачи.
- **Управляемая лента:** переключатель Shorts, компактные карточки поиска и медиатеки, точные даты публикации из player/watch metadata либо честные относительные подписи YouTube и стабильная сортировка новых роликов выше старых там, где порядок не задан пользователем. Обновление и подгрузка «Главной» сохраняют уже показанные карточки и позицию, добавляют страницы без дублей и не смешивают отдельные источники каталога. История сохраняет хронологию просмотра, а содержимое пользовательских плейлистов — порядок владельца; при этом карточки роликов используют общий достоверный publication metadata pipeline.
- **Matrix UI:** полноценные системная, тёмная и светлая темы с live-переключением, общей семантической палитрой, адаптивными карточками, safe-area для мини-плеера, Dynamic Type и VoiceOver.
- **Семантическая тактильность:** навигация, выбор контента, транспорт, retry, успешные операции и разрушительные подтверждения используют разные нативные уровни haptic feedback; пассивный рендер, прокрутка и непрерывный progress не вибрируют.
- **SponsorBlock и DeArrow:** поддержка сегментов SponsorBlock и общественных названий/обложек DeArrow.
- **Интеграции:** Share Extension и Safari Web Extension для открытия YouTube-ссылок в iPocketTube.
- **Вход:** Google/YouTube device-code flow для подписок, истории и плейлистов; выход из аккаунта является версионированной границей — запоздавший refresh, обмен cookies или callback API не может восстановить завершённую сессию.
- **Без обязательной инфраструктуры:** приложению не нужен отдельный iPocketTube-сервер, Invidious/Piped и обязательный Firebase-проект.

Основной аудио-first путь получает выбранный медиапоток контента напрямую и не открывает рекламный web-player. При этом YouTube меняет backend и форматы без уведомления, поэтому проект не обещает абсолютную вечную блокировку любых будущих рекламных или ограничительных механизмов.

## Ограничения

- Используется неофициальный YouTube/InnerTube backend, который может измениться и временно нарушить поиск, metadata или получение медиапотока.
- YouTube не всегда раскрывает язык аудио. Поэтому строгий русскоязычный поиск намеренно исключает ролики без достаточных метаданных и не пытается угадывать язык по одному заголовку.
- Возрастные, региональные, платные, DRM-защищённые и другие restricted-видео могут быть недоступны.
- iOS не гарантирует фоновую работу после явного force-quit приложения пользователем; незавершённые задания сверяются и продолжаются при следующем запуске.
- iPocketTube не обходит DRM и не публикует cookies, токены или подписанные media URL.
- Сохраняйте только контент, на загрузку и использование которого у вас есть право.

## Сборка из исходников

Требуются Xcode 16+, iOS 17+ и собственная Apple Developer Team для подписи на физическом устройстве.

```bash
git clone https://github.com/axrbarsic/iPocketTube.git
cd iPocketTube
open iPocketTube.xcworkspace
```

1. Выберите схему `iPocketTube` и свой iPhone.
2. В `Signing & Capabilities` назначьте собственную Team и включите automatic signing для приложения и пользовательских extensions. Не коммитьте Team ID, provisioning profiles, сертификаты и приватные конфиги.
3. Соберите и запустите приложение из Xcode.

Firebase не обязателен для персональной сборки. Если вы отдельно подключаете Firebase/Crashlytics, используйте собственный игнорируемый `GoogleService-Info.plist` и ознакомьтесь с его политикой обработки данных.

```text
iPocketTube/          Swift Package: модели, InnerTube, playback/download state, SwiftUI
iPocketTubeApp/          Xcode project: iOS app, Share/Safari extensions, Live Activity
iPocketTube.xcworkspace/ Рабочее пространство Xcode
```

Адресные тесты Swift Package:

```bash
swift test --package-path iPocketTube
```
